# E-Commerce Application (Java)

## 📌 About the Project
This project is a **GUI-based E-Commerce Application** developed using Java. It was one of my **first software projects**, created to practice Object-Oriented Programming concepts and basic user interaction with a graphical interface.

---

## 🖥️ Project Features
- Graphical User Interface (GUI)
- Product listing with icons
- Add products to cart
- Purchase products
- Add and remove products from favorites
- User-friendly design for basic e-commerce flow

---

## 🧠 Programming Approach
- The project is developed using **Object-Oriented Programming (OOP)** principles
- Each main feature is separated into classes (Product, User, Cart, etc.)
- The code structure is simple and easy to understand

---

## 💾 Data Storage
- User information, products, and credit card data are stored in **.txt files**
- File operations are used to read and write data
- This approach was chosen to understand basic file handling logic

---

## 🛠️ Technologies Used
- **Language:** Java
- **GUI:** Java Swing
- **Concepts:** OOP, File I/O, GUI programming

---

## 🎯 Purpose
The main purpose of this project is to:
- Learn Java GUI development
- Understand object-oriented design
- Build a complete small-scale application

This project represents an important learning step in my software development journey 🚀
